# DecodeLabs Internship Projects

## Project 1: Data Cleaning
Cleaned a raw e-commerce order dataset by identifying and handling missing values, 
checking for duplicates, and verifying correct data formats using Python and pandas.

- Found and filled 309 missing CouponCode values
- Verified no duplicate rows or Order IDs
- Confirmed correct data types (dates, numbers, text)

Files: `clean_data.py`, `Dataset for Data Analytics.xlsx` (raw), 
`Cleaned Dataset for Data Analytics.xlsx` (cleaned)

## Project 2: Exploratory Data Analysis (EDA)
Analyzed the cleaned dataset to identify trends, outliers, and key business insights 
using Python, pandas, and matplotlib.

- Calculated summary statistics (mean, median, min/max)
- Identified outlier orders and confirmed they were legitimate bulk purchases
- Found that Cancelled orders outnumbered Delivered orders
- Visualized order status, product value, and monthly sales trends

Files: `chart1.py`, `chart2.py`, `chart3.py`, `summary.txt`, chart images (.png)

**Tools:** Python (pandas) and/or Excel
